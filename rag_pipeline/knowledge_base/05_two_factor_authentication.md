## EN

Two-factor authentication (2FA) works like a second lock on a door: even if an attacker obtains your password, they still need a second key — a verification code — to get in. CIRT-CM identifies it as one of the most effective defenses against account takeover. In Cameroon, WhatsApp and Facebook accounts are frequently hijacked, and in most of these cases 2FA, if enabled, would have stopped the attack.

A scenario that plays out constantly: someone messages you on WhatsApp claiming they "accidentally" sent a verification code to your number and asks you to forward it back to them. This is a trap — that code is actually your own account's verification code, and sharing it hands over control of your WhatsApp to the attacker, who then uses your account to scam your contacts. A related variant: an SMS claims your Mobile Money account is blocked and asks you to send your verification code to "unblock" it — never respond to this. Another variant is a fake telecom "technician" who calls and asks you to read out an SMS code "to secure your line" — this is typically a SIM-swap attempt.

To enable 2FA on common platforms: on WhatsApp, go to Settings → Account → Two-step verification and set a 6-digit PIN; on Facebook, go to Settings → Security and Login → Two-Factor Authentication; on Gmail, go to your Google Account → Security → Two-Step Verification; on Instagram, go to Settings → Security → Two-Factor Authentication. The golden rule across all platforms: never share an OTP (one-time password) code received by SMS with anyone, even someone claiming to be a friend or an "agent." Where possible, prefer an authenticator app (like Google Authenticator or Microsoft Authenticator) over SMS codes, since SMS-based codes can be intercepted through increasingly common SIM-swap attacks, and authenticator apps work even without internet access.

## FR

L'authentification à deux facteurs (2FA) fonctionne comme une double serrure sur une porte : même si un pirate obtient votre mot de passe, il lui faut encore une deuxième clé — un code de vérification — pour entrer. Le CIRT-CM la considère comme l'une des défenses les plus efficaces contre le piratage de compte. Au Cameroun, les comptes WhatsApp et Facebook sont fréquemment piratés, et dans la plupart des cas, l'activation du 2FA aurait empêché l'attaque.

Un scénario très fréquent : quelqu'un vous écrit sur WhatsApp en prétendant avoir envoyé un code « par erreur » à votre numéro et vous demande de le lui retransmettre. C'est un piège — ce code est en réalité le code de vérification de votre propre compte, et le partager donne le contrôle de votre WhatsApp au pirate, qui s'en sert ensuite pour arnaquer vos contacts. Variante associée : un SMS affirme que votre compte Mobile Money est bloqué et vous demande d'envoyer votre code de vérification pour le « débloquer » — ne répondez jamais. Autre variante : un faux « technicien » télécom vous appelle et vous demande de lui lire un code SMS « pour sécuriser votre ligne » — il s'agit typiquement d'une tentative de SIM swap.

Pour activer le 2FA sur les principales plateformes : sur WhatsApp, Paramètres → Compte → Vérification en deux étapes, puis définir un code PIN à 6 chiffres ; sur Facebook, Paramètres → Sécurité et connexion → Authentification à deux facteurs ; sur Gmail, Compte Google → Sécurité → Validation en deux étapes ; sur Instagram, Paramètres → Sécurité → Authentification à deux facteurs. Règle d'or sur toutes les plateformes : ne partagez jamais un code OTP reçu par SMS, même avec un proche ou un prétendu « agent ». Dans la mesure du possible, préférez une application d'authentification (Google Authenticator, Microsoft Authenticator) plutôt que les SMS, car les codes par SMS peuvent être interceptés via des attaques de type SIM swap de plus en plus fréquentes, et ces applications fonctionnent même sans connexion Internet.
